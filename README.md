# JavaScript Technical Documentation Page

## 📖 Project Description

This project is a **simple technical documentation webpage** built using **HTML and CSS**.  
It follows the common structure of real documentation websites such as **JavaScript, Python, Java, and Arduino docs**, with a left navigation bar and content displayed on the right.

This project is designed for beginners who want to practice **HTML structure, CSS layout, internal linking, and responsive design**.
